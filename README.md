# Udemy Front Page Clone

A frontend clone of the Udemy homepage built using **HTML5** and **CSS3**. This project replicates the design and layout of Udemy’s landing page, featuring a responsive navigation bar, course categories, promotional banners, and course cards. It is designed to provide a seamless user experience across devices and showcases my frontend development skills with attention to UI/UX design.

---

## 🔨 Tech Stack:
- **HTML5**
- **CSS3**

---

## 📱 Features:
- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop views.
- **Clean and Modern UI**: Replicates Udemy’s homepage layout with an interactive feel.
- **Functional Navigation**: Includes sections like course categories and promotional banners.
